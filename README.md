# Portafolio Profesional - Matías Mansilla

Portafolio profesional desarrollado como parte de la asignatura **Desarrollo Fullstack II**.

El objetivo del proyecto es presentar mi perfil profesional, habilidades técnicas,
proyectos desarrollados y un medio de contacto, aplicando conocimientos de
HTML5, CSS3, JavaScript, Git y GitHub.

Este portafolio corresponde a un sitio web personal en el que se presentan

## Diseño responsive

El sitio fue desarrollado para adaptarse a diferentes tamaños de pantalla.

Mediante CSS y Media Queries se modifica la distribución de los elementos
para mejorar la visualización en:

- Computadores
- Tablets
- Dispositivos móviles

---

## Validación del formulario

El formulario de contacto utiliza JavaScript para comprobar los datos
antes de realizar el envío.

Las principales validaciones son:

- El nombre debe contener al menos 3 caracteres.
- El correo debe tener un formato válido.
- El mensaje debe contener al menos 10 caracteres.

Cuando un campo contiene información incorrecta, se muestra un mensaje
de error y se evita el envío del formulario hasta que los datos sean válidos.
